# D1-Fabric

**面向 Cloudflare Workers 与 D1 的数据库中间件底座**

D1-Fabric 是一个面向现代 Serverless 架构设计的数据库中间件与数据基础设施底座，位于业务应用与底层数据库之间，为上层系统提供统一的数据路由、分片管理、物理目标解析、执行控制、可靠性与故障恢复能力。

D1-Fabric 将逻辑数据库、逻辑分片与实际物理数据库目标进行解耦，使业务应用无需直接依赖具体数据库实例。随着数据规模增长，可以通过统一的控制与路由机制实现数据库扩展、分片迁移、重平衡和故障处理。

## 核心能力

**统一数据路由**  
根据逻辑数据库、逻辑分片和版本信息，将请求解析到正确的物理数据库目标。

**分片与扩展管理**  
提供分片生命周期管理、扩容规划、数据迁移与重平衡能力，支持持续增长的数据工作负载。

**可靠执行**  
提供超时控制、重试预算、熔断、故障分类和执行保护机制，降低分布式数据库操作风险。

**版本与并发控制**  
通过分片映射版本与控制纪元等机制，防止过期路由、旧状态和无效执行。

**幂等与恢复**  
通过幂等与恢复机制，降低重复执行、未知提交和故障恢复过程中的数据风险。

**控制与执行分离**  
将权威控制状态与数据执行职责分离，使数据库管理和业务执行边界清晰。

**Serverless 原生设计**  
围绕 Cloudflare Workers、D1 与 Service Binding 构建，同时保留向其他数据库平台和基础设施演进的空间。

## 架构定位

D1-Fabric 不是业务数据库，也不是业务 ORM。

它位于应用层与数据库基础设施之间：

**业务应用 → D1-Fabric → 数据库实例 / 数据库集群**

D1-Fabric 负责数据库目标解析、路由、执行可靠性、扩展、迁移和生命周期管理，让上层业务专注于业务逻辑，而不需要直接管理底层数据库拓扑。

## 项目目标

D1-Fabric 的目标，是为现代高并发、Serverless 和数据驱动型应用提供稳定、可扩展、可演进的数据库基础设施层。

项目强调**清晰的职责边界、可靠的数据访问、可控的数据库扩展，以及长期的基础设施演进能力**。

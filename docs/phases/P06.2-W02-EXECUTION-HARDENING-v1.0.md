## Objective

Harden W02 without changing its fixed four-Worker architecture. This packet closes two execution-accounting defects found during independent review:

1. admitted scheduler work must settle before terminal failure;
2. bounded D1 read execution must account the adapter-reported `rows_read` metric rather than treating returned result count as the authoritative D1 read metric.

## H01/H02 invariants

- Existing admitted work is bounded by the already reserved concurrency/fanout.
- On scheduler failure, no new work may be admitted after terminal failure.
- Already admitted work must settle before the scheduler reports the terminal failure to its caller.
- The scheduler must not retry failed work.
- Resource reservations must have a terminal state; no admitted work may remain logically in-flight after the scheduler returns or throws.
- `Promise.all(N)` and unbounded promise creation remain forbidden. Settlement may use a bounded collection whose size is at most the scheduler concurrency budget.

## Read accounting invariants

- The D1 adapter must expose a non-negative safe-integer `meta.rows_read` for authoritative row-read accounting.
- `result.results.length` is response-item count, not authoritative D1 rows-read usage.
- Response-item count remains independently bounded by the read contract.
- If authoritative `rows_read` exceeds the reserved row budget, the execution must fail closed.
- The read result must report the authoritative `rowsRead` value and resource ledger using that value.
- No additional D1 statement may be introduced for accounting.

## Security / architecture invariants

- No physical D1 identifiers are returned.
- No business semantics are introduced.
- No routing source of truth is added.
- No retry policy is added.
- Cache termination semantics remain unchanged.
- W02 remains execution-only.

## Required tests

1. scheduler task failure settles all already-admitted tasks before the failure is returned;
2. scheduler admits no additional task after terminal failure;
3. scheduler never exceeds configured concurrency during failure;
4. D1 `meta.rows_read` is used for resource accounting;
5. response-item count and authoritative rows-read can differ;
6. authoritative rows-read over budget is rejected;
7. cache HIT remains zero D1 work;
8. no physical topology disclosure;
9. existing W02 regression suite remains green.

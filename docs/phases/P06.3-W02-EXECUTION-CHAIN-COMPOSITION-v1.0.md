## Objective

Prove the existing W02 execution stages compose without violating phase ownership, budgets, ordering, failure containment, or topology boundaries.

## Required chain

`P04 compile -> P05 route -> P06 bounded admission -> P07 bounded read`

The test is a composition proof only. It MUST NOT introduce a new production runtime primitive or replace the phase contracts.

- `workers/v2/W02-Execution-Fabric/tests/**`

- `docs/phases/evidence/P06.3.1-EVIDENCE.md`

## Forbidden

- W01/W03/W04 changes
- new Worker/runtime primitive
- business logic
- new routing algorithm
- physical database/shard identifiers
- write/mutation paths
- retry loops
- cross-shard execution
- unbounded promises or `Promise.all(N)`
- changing P04/P05/P06/P07 production implementation

## Invariants

1. P04 output is routable and contains no physical topology.
2. P05 resolves only a tenant-scoped logical target.
3. P06 admission remains bounded by fanout and concurrency.
4. P06 failure settles already-admitted work before terminal return and admits no new work after failure.
5. P07 consumes only the logical target plus validated placement supplied by the test boundary.
6. A valid cache termination produces zero D1 statements.
7. A D1 read consumes exactly one statement and uses authoritative `meta.rows_read`.
8. Budget accounting never reports consumption above reservation.
9. A stage failure prevents downstream execution.
10. No physical topology identifier crosses the W02 public result boundary.

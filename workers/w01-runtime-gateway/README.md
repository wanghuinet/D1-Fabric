# W01 Runtime Gateway

Generic runtime/request boundary for D1-Fabric.

## Scope

- request ID and runtime boundary
- deadline/context handling
- CORS
- execution entry

Business semantics, business ownership, and business data rules do not belong here.

## Standalone commands

```bash
npm ci
npm run typecheck
npm run smoke
npm run build
npm run deploy
```
